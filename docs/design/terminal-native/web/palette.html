The palette

命令面板 · 主页之上的浮层

One grammar for the palette and the slash menu. The idle list follows the insertion order of SLASH_COMMANDS; a non-empty query is a case-insensitive subsequence — needle and haystack are both lower-cased, the characters appear in order and need not be contiguous — matched against the canonical name, the slash name without its slash, or an alias with one leading slash stripped. Matches rank by exact haystack, prefix haystack, gap cost, start index, then canonical name, and the menu shows at most 60 rows. Arguments are a different rule: a case-sensitive unique prefix of an id or name. Open it with Ctrl+K, or with / when the composer caret is at column 0.

    Fuzzy matches

    A case-insensitive subsequence over three haystacks: the canonical name, the slash name without its slash, and each alias with one leading slash stripped — needle and haystacks lower-cased. Rank: exact haystack, prefix haystack, lower gap cost, earlier start index, canonical name. The gap cost is end − start − (needle − 1), so a contiguous run costs 0. Each command ranks by its best haystack.
    dspdispatch — d at 0, s at 2, p at 3; gap cost 1; nothing else matches
    DSPdispatch — folded to dsp first, so the same row and the same indexes
    Dispdispatch first — a prefix of the canonical name, gap cost 0
    jobstickets — matched on the alias jobs (exact), not on the canonical name
    tkttickets — t at 0, k at 3, t at 5; gap cost 3
    apvapprove — a at 0, p at 1, v at 5; gap cost 3
    mememory, merge (prefix hits), then resume (m at 4, e at 5; gap cost 0) and model (m at 0, e at 3; gap cost 2)
    zzzno rows — the list shows the empty state no command matches · 没有匹配的命令

    Keyboard model

    One model for the web and the TUI. The open palette is a focus trap: the query, then the result list.
    Ctrl+KOpen the palette from anywhere that is not already inside the palette.
    /Open the palette, prefilled with /, when the composer caret is at column 0.
    EscClose the palette, clear its query, and return focus to the opener.
    ↓ ↑Move the highlight while the query has the caret; next/previous row in a focused list.
    j kNext/previous row when the result list (or another list) is focused, or in navigation mode. In the query they are the characters j and k.
    Alt+NToggle palette navigation mode; the chrome shows nav. Off when the palette opens.
    Ctrl+↓ Ctrl+↑Move focus query → result list, and back.
    EnterRun a complete form; on an incomplete form insert the highlighted argument, or show the error hint. In a composer, send.
    TabNext stop in the focus order. Inside the open palette, accept the highlighted token (plus a space when the form still needs an argument); never leaves the palette.
    Shift+TabPrevious stop in the focus order — never rebound. Inside the open palette it is inert.
    Alt+MCycle mode auto → dispatch → read-only; the chip in the top bar shows it (hint alt+m mode, was shift+tab mode).
    Shift+EnterNewline in a composer (Ctrl+J also works). Enter sends.

    j 和 k 在查询框里永远是字符（即使查询为空），因为命令本身含有 j 和 k（jobs、reject）； 用 ↑/↓ 移动高亮，或按 Alt+N 进入导航模式。焦点顺序：主列表（或转录）→ 输入框；Shift+Tab 反向移动，从不被改绑。
