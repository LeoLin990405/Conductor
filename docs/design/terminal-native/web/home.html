#56 调色板查询框里 j/k 始终是字符，只在结果列表或 Alt+N 导航模式下移动高亮

TUI 与 web 的调色板遵守同一条边界：查询框里 j/k 是字符，即使查询为空；只有焦点在结果列表上，或 Alt+N 导航模式开启时，它们才移动高亮。

Both palettes keep one boundary: j and k are characters in the query, even when it is empty; they move the highlight only on the focused result list or in Alt+N navigation mode.
