合并彩排现在读取被评审的提交，而不是 HEAD。彩排在一个一次性的 worktree 中进行， 测试在那里跑完，索引通过独立的 GIT_INDEX_FILE 隔离，主工作区的暂存区不受影响。 彩排通过之后，git update-ref 以 compare-and-swap 的方式只接受那一个提交； 如果目标引用在彩排期间被移动，交换失败，目标分支保持原样。临时目录在 finally 中删除，失败路径也不会留下残留。

The rehearsal now reads the reviewed commit instead of HEAD. It runs in a throwaway worktree with an isolated index, so the main staging area is untouched. Only the rehearsed commit is landed, through a compare-and-swap git update-ref that fails closed when the target ref moved during the rehearsal. The throwaway directory is removed in a finally block on every path.
