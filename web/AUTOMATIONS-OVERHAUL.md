# 自动化页完全优化（第一轮）

## 视觉

- 空状态从「清单行」改为 **模板卡片网格**：图标 tile、名称、说明、底部 cadence（星期/时间），hover 抬升；
  背景的「未来 feed」区域改为虚线卡片画布，不再是被遮罩截断的纹理条。
- 页头在空状态也显示 **新建自动化** 主按钮（之前空状态没有任何操作入口）；有数据时保留 动态/管理 切换。
- Feed 的每次运行从表格行改为卡片（hairline、圆角、hover 抬升）；运行日标题更轻。
- 管理视图右侧详情改为 **卡片面板**（标题/排期/操作/指令/运行记录/详情），段落之间用 hairline 分隔。
- 创建/编辑表单改为 **聚焦卡片**：白色/墨色面板、圆角与阴影，和详情页同语汇。
- 移动端单列卡片，底部留出 tab bar 空间。

## 性能

- `ManageView` 与 `AutomationInlineForm` 改为按需加载，构建产物确认独立 chunk：
  `ManageView-*.js` / `AutomationInlineForm-*.js`；打开 feed 不再加载表单与价格/投递选择器。
- 空状态 Starters 仍在页面 chunk（首屏需要）。

## 文案

- 新增 `automation.startHint`（模板说明）与 `automation.emptyHint`（空画布 CTA），中英文同步；
- 空状态不再只有一句「发现会出现在这里」，给出明确下一步。

## 验收

- `tsc -b` / `pnpm build` 通过；页面无运行时错误
- 真实 E2E：从「早盘简报」模板创建自动化 → 管理视图卡片渲染 → 删除，自动化数量恢复 0（未留测试数据）
- 截图：72（改前）、74（新空状态）、75（表单）、76/77（管理视图）、78（feed）、79（移动端）
